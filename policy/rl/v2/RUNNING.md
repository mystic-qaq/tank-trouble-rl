# V2 初始化实验

> 当前状态：本批已完成初始化验收，四个候选均按门槛停止，PPO 未启动，GPU 已释放。详见 [V2b 最终结果](RESULTS_V2B.md)。下文为本批配置和操作记录。

本轮仅运行有上限的数据、BC、一次 DAgger 和初始化验收。旧 V1 维持 `stopped_by_user`，不恢复其模型或优化器。
初始化报告生成后停止本批程序；PPO 需要对应检查点的 G0–G3 全部通过，不能以离线动作准确率替代实战验收。

## 路径与资源

- 服务器：`gpu-host`，工作目录 `$RL_ROOT`。
- 源码快照：`$RL_ROOT/releases/20261106-v2b`，启动前设为只读。
- 结果：`$RL_ROOT/runs/v2b`。
- 主程序 tmux：`tank-v2b-initialization`；TensorBoard：`tank-v2b-board`。
- 采样：HY 24 个、GPT 24 个、技能 16 个环境 worker，总计最多 64 个；每位教师至少 1,000 个完整场景和 20,000 次真实发射。
- 技能：2,400 条完整轨迹，静止目标、移动目标、反弹、贴墙、躲弹和齐射各约 400 条。每帧使用原引擎 1/60 秒更新。
- 数据阶段上限 7,200 秒，结束前排空已在途的完整轨迹，外层超时上限 7,380 秒。
- 绑定四张空闲 GPU 的 UUID，避免 CUDA 枚举顺序与 nvidia-smi 编号不一致。具体分配写入 `gpu-allocation.json`。
- 四个候选：HY/GPT × 开火正样本权重 1/4；种子 11/29。每个候选至多 3,600 秒，包含初始 BC、技能评估、最多一次 DAgger、再训练和实战验收。
- 本批不会自动进入长 PPO，也不会替换正式 Bot 或 minimax。

## 实时查看

TensorBoard 远端仅监听 `127.0.0.1:6006`。本机转发 `127.0.0.1:16006`：

```powershell
ssh -N -L 127.0.0.1:16006:127.0.0.1:6006 gpu-host
```

打开 http://127.0.0.1:16006 。数据采集阶段查看 `collect/*`，梯度训练开始后查看 `train/*` 与 `validation/*`；实战指标在 `eval/*`。
验证曲线的开火精度/召回按保留概率加权，还原自然的合法开火机会；技能演示和 DAgger 标签不混入教师留出集的 G2 指标。
采集计数的“真实发射”只来自引擎新建子弹，DAgger 另外记录反事实教师标签，二者不混算。

```powershell
ssh gpu-host '$RL_ROOT/.venv/bin/python $RL_ROOT/releases/20261106-v2b/policy/rl/v2/status.py --run $RL_ROOT/runs/v2b'
```

`pipeline.json` 显示阶段；`data/*/status.json` 显示覆盖与吞吐；`win-fw*/gates.json`、`frag-fw*/gates.json` 显示各道门槛。
SSH 断线不影响 tmux 中的实验。本地端口转发断开后，重新执行转发命令即可。

## 本轮门槛

- G0：冻结策略、60 秒规则、奖励与重放、事件账本、二进制传输、动作概率及序列化的一致性测试全部通过。
- 覆盖：HY/GPT 各至少 1,000 个场景、20,000 次真实发射。
- G1：六类留出微任务各 50 局，成功率达到同条件参考的 90%；参考自身需达到 90%，自毁率不超过 2%，贴墙哑火不超过每局 0.02。
- G2：教师自然合法机会上的开火召回至少 80%、精度至少 70%，留出真实发射正例至少 200。当前固定工程筛查，未通过不绕过。
- G3：2–8 人各至少 100 局，完整地图和座位轮换；按共享布局块 bootstrap，学生减去 0.8 倍教师主指标的 95% CI 下界非负，且学生确有击杀。教师净击杀基线非正时暂停相对门槛，另行审查绝对收益。

G3 使用 738 个成对场景，每一方都跑完整世界回合；训练采样可在自身未来奖励已不可能变化时结束代理轨迹。
本批数据、微任务和开发评估使用不同 seed 空间。最终测试集尚不参与选择。

## 前置探针与限制

- 引擎对照逐帧一致；六类参考各 50 局全部成功。该成绩属于参考控制器，不属于学习模型。
- GPT 64 局探针：473 次真实发射、3,909 条保留样本；HY 64 局：530 次真实发射、8,795 条保留样本。
- 小规模采集、CUDA BC、学生闭环评估、DAgger 标签与回训接口已做冒烟验证。100 步 BC 的学生仍不射击，不能据此称模型已学会战斗。
- V2 的 PPO 文件实现了完整代理回合、gamma/lambda=1、独立 critic 和旧概率检查，并由初始化验收文件与模型哈希锁定。本批不会调用它；正式短试验前仍需完整 GPU 更新回归。
- 模型文件保存/加载的动作解码已验证；未来浏览器部署导出另需与 Python actor 做固定观测和整局回放验收。

开发目录在启动后补充修复并测试了未启用 PPO 路径的 warmup 随机种子边界。只读 `20261106-v2b` 不做热修改，且本批不调用 PPO。
后续短 PPO 必须从更新后的开发源码建立新快照，重新完成契约与完整 GPU 更新回归；不要直接调用 V2b 快照里的 PPO 草案。
