# 首轮学习效果诊断

日期：2026-11-06。依据：既有训练日志、52.4 万帧开发评估、教师留出状态上的动作审计与阈值扫描。
诊断脚本只读取数据/检查点，在独立进程运行，不改变现有训练。

## 判断

目前主要应优先处理训练设计，而不能只等待更多帧。训练量确实还小，尚不足以判断强化学习路线能否超过 HY/GPT；
但已有行为证据表明初始化没有学会攻击，净击杀模型进一步收敛到接近不射击的行为。

首版以固定 30 个 BC epoch 后直接进入 PPO，没有设置关键动作与实战能力准入门槛。这是应修正的流程缺口。

## 已观察到的事实

| 项目 | 胜率模型 | 净击杀模型 |
| --- | --- | --- |
| 训练集状态动作数 | 52,336 | 54,008 |
| 其中教师开火样本 | 354 | 597 |
| 留出状态数 | 13,200 | 11,528 |
| 留出教师开火样本 | 77 | 90 |
| BC 移动三分类准确率 | 92.5% | 95.6% |
| BC 转向 MAE（[-1,1]） | 0.140 | 0.309 |
| BC 默认确定性开火召回率 | 0% | 0% |

BC 后，胜率模型在留出状态上的最大开火概率约 0.092，净击杀模型约 0.246，均未达到默认 0.5 决策阈值。
因此即使总损失下降、移动分类很准，默认确定性推理仍无法在这些状态中复现一次教师开火。

在同一批 28 局开发场景中：

| 策略 | 胜率 | 净击杀/局 | 击杀/局 |
| --- | --- | --- | --- |
| HY 教师 | 39.3% | 0.786 | 0.893 |
| GPT 教师 | 14.3% | 0.714 | 0.821 |
| 胜率模型 BC | 3.6% | 0 | 0 |
| 胜率模型 PPO 524,288 帧 | 3.6% | 0 | 0 |
| 净击杀模型 BC | 3.6% | 0 | 0 |
| 净击杀模型 PPO 524,288 帧 | 7.1% | 0 | 0 |

28 局不能用于精确排名或小幅提升判定；但连续零击杀与离线零开火召回率互相印证，是应优先排查的行为故障。

净击杀模型在 10–60 万帧的多个十万帧训练窗口里，击杀/局为 0，自毁率持续降低，净击杀逐渐趋近 0。
约 78.6 万帧时，它在教师留出状态上的最大开火概率约 0.00243，甚至阈值降到 0.01 仍不会开火。
这说明训练曲线的改善主要体现为避免自毁，尚不是有效攻击能力的进步。

## 原因及证据强度

1. **BC 的罕见开火事件没有学好：已证实。** 总共 65,536 帧只对应 57/125 个已结束的采集回合，连续帧高度相关；
   真正的训练开火标签只有数百条。损失/epoch 结束条件未保证关键技能可用。
2. **概率校准与确定性决策需要联合验证：已证实。** 首版对加权二分类做概率校准后使用 0.5 阈值，BC 输出全部低于阈值。
   校准公式本身不等于计算错误，但在当前欠拟合分类器和决策方式下导致不射击。
   降低阈值能增加 BC 射击，但与教师不一致的射击也显著增加，必须检查实战命中和自伤，不能仅改阈值宣告修复。
3. **净击杀目标下的不射击局部最优：有强行为证据。** 正收益攻击样本很少，自毁负反馈较多；降低射击概率能迅速改善回报，
   随后几乎不再探索到正收益攻击。最终目标“击杀−自毁”仍正确，不应长期给每次开枪加分来伪造进步。
4. **胜率模型的长程信用分配困难：从配置可推导，但需消融验证贡献。** γ=1、λ=.98、60 Hz、rollout=256。
   每段约 4.27 秒，5 秒之前的直接 GAE 残差系数为 .98^300≈0.00233。
   这并不是只能看 0.8 秒，价值函数仍可通过 bootstrap 表达长程收益；但早期 critic 不准确时对终局稀疏信号依赖很强。
5. **输入表示与课程难度：待消融验证的假设。** 小网络需要从墙网格和压缩实体集合中自己推断遮挡、反弹和有效瞄准，
   初始就混合 2–8 人强策略。更好的公共几何特征和分阶段课程可能比仅增加网络参数更有效。

## 下一版的优先顺序

1. 保留本轮及其数据作为对照，新增版本，不在训练中途混改奖励、输入或测试动作规则。
2. 先修复“能有效射击”的初始化：更多独立回合与开火/瞄准关键样本；在可开火条件下学习开火；
   同时记录召回率、精度、转向误差、真实发射数、击杀、自毁，按实战结果选择动作解码。
3. 将学生自己运行后的状态交给教师补充标签（DAgger 式数据聚合），处理学生偏离教师轨迹后的分布偏移。
4. 设置 BC 实战准入门槛。建议先将达到教师同场景关键成绩的约 70–80% 作为工程目标，并要求有效攻击与自伤率可接受；
   这是建议门槛，需足够回合/置信区间，不是普遍理论保证。
5. 从可见目标射击、避弹、反弹自伤微任务和简单 1v1 开始，再逐步加入复杂地图、强对手和 3–8 人。
   最终恢复约定的随机对局分布验收。
6. 加入公共状态可计算的局部墙体/射线、目标遮挡与角度、来弹威胁特征，保持物理规则与动作能力不变，做输入表示消融。
7. 初始化达标后再比较更长 rollout、较长 GAE trace、按动作头分别管理探索、与行为质量挂钩的教师约束衰减。
8. 只有固定场景的击杀、净击杀和胜率持续改善后，才扩大训练预算。训练总 reward 和 GPU 利用率均不能替代这些门槛。
